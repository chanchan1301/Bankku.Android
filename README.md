# DompetKu Android APK Builder

1. Ekstrak ZIP.
2. Unggah **isi folder ini** ke root repository GitHub (jangan bungkus lagi dalam folder tambahan).
3. Buka tab Actions, jalankan workflow **Build DompetKu APK**.
4. Setelah selesai, unduh artifact `DompetKu-APK` dan ekstrak `app-debug.apk`.
5. Pasang APK di Android; izinkan instalasi dari sumber unduhan bila diminta.

Ini debug APK untuk uji/pemasangan, bukan rilis Play Store bertanda tangan. Data keuangan disimpan lokal; login, sinkronisasi online/Supabase, dan AI online belum diaktifkan.
